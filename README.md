# Office Artifacts: The One-Line Placard

A program that writes a single-line museum placard for an ordinary
office stapler, recast as an ancient ritual artifact, to
`/output/entry.txt`.

## Run

```sh
python3 main.py
```

The placard (168 characters):

> Stapler, c. 1997, pressed steel. Ritual binding instrument: two sheets joined before witnesses, never to part. Gift of the Accounts Department, in memory of the merger.
